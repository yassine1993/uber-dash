⚠️ This App Cannot Run on Netlify

This is a Streamlit application that requires a persistent Python server. Netlify is designed for static websites and cannot host Streamlit apps.

This app should be deployed to Streamlit Cloud instead.

Quick Deployment Steps:

  • Go to share.streamlit.io
  • Sign in with GitHub
  • Select repository: yassine1993/uber-dash
  • Set main file: app.py
  • Click "Deploy"
